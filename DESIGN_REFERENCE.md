# Design direction

The visual direction is inspired by the qualities of large cinematic corporate technology websites:
- fullscreen motion-led hero
- oversized editorial typography
- strong black/navy visual field
- restrained navigation
- high-impact business-unit sections
- large negative space
- strong section rhythm

It does not copy KRAFTON source code, assets, logos, imagery, layout, or video.
The ARESTER hero video is an original 10-second abstract MP4 created for this project.
Original ARESTER logo files remain unchanged.
